# Laravel demo (planned — phase 5 of the kickoff)

A minimal Laravel app demonstrating the `modern-spf` protocol:

- routes detect `?spf=navigate` and respond with a single SPF JSON object
- a streaming route responds `application/x-spf+ndjson` with parts
- views use `class="spf-link"` for dynamic navigation
- shows the `spf-link` / `spf-nolink` / `spf-no-transition` classes in action

Not scaffolded yet. Will be added during phase 5.
